# DriveFleet / Optimus Experience

Sistema completo de gestão para locadoras de veículos e motoristas de aplicativo.

## Tecnologias
- **Frontend**: React + Vite + Vanilla CSS (Glassmorphism UI)
- **Backend**: Node.js + Express
- **Banco de Dados**: MySQL (com fallback offline para resilência local)

## Funcionalidades
- **15 Áreas Administrativas Integradas**: Interessados, Clientes, Motoristas, Veículos, Reservas, Contratos, Locações, Cobranças, Fluxo de Caixa, Manutenções, Vistorias, Multas, Sinistros, Suporte e Relatórios.
- **Dupla Filtragem em Tempo Real**: Filtros combinados por busca textual + filtros por Categoria, Status ou Tipo em todas as tabelas.
- **Fluxo Guiado Completo**: Conexão automática desde o cadastro no formulário do site até o contrato e locação do veículo.
